# 接力台设计说明

给以后改代码的人（和 AI）看的。用户手册见 [README](../README.md)。

## 一句话

几个 AI 在**同一个隔离副本**里轮流干活；每换一次人都「交接」一次（存检查点 + 跑检查 + 写审计）；最后把整个任务**压成一个提交**合回正式文件夹。全自动模式把「谁上岗、何时交接、谁来审、改不改、何时合回」全交给程序，按交接记录一步步推。

## 不变的规矩

1. **事实只认 git**。审计报告的事实段、审查请求里的改动，全部由 git 生成；AI 自己说的（NOTE.md、最后一句话）只作「自述」，标明不是事实。
2. **正式文件夹不动**，直到合回。隔离副本建在仓库外（`~/.relay/worktrees/<项目键>/<分支>`），正式文件夹的 `git status` 一直干净。
3. **交接记录只追加**（`.relay/journal.jsonl`）。退回、同步都是新记一笔，不改写历史；接力分支合回后保留备查。
4. **同一时间只有一个写者**：`.relay/session.lock` 有三种锁（终端进程锁、桌面软锁、接力台操作锁）；全自动用终端锁，pid 是接力台进程。
5. **兼容旧数据**：只加可选字段、只加新事件类型；旧 journal、旧工人名单照样能读。
6. **密钥不落盘**：配置里只写环境变量名；要用别的工具保存的密钥（`keyFrom`），必须用户同意，而且只在调用时读进内存。发给外部模型的材料先脱敏。
7. **宿主凭据隔离**：接力台如果是在某个 AI 工具的会话里启动的（`CLAUDECODE` 等），`CLAUDE_*` / `ANTHROPIC_*` 这类会话变量一律不传给子进程、也不当作用户的密钥（`core/env.ts`）。

## 目录

```

    providers.ts  模型接口：密钥 → 接口地址 → 列模型；Codex / MiMo 配置里登记的接口
    detect.ts     自动识别汇总、并进工人名单、谁能干活 / 审查、排团队
    runner.ts     跑一个工具：进程组、超时、叫停、把各家输出翻成中文日志、取最后一句话
    llm.ts        OpenAI / Anthropic 两种协议的一问一答、列模型、带工具的多轮对话
    llm-agent.ts  内置小代理：接口模型通过 6 个工具改隔离副本
    review.ts     审查请求、宽容地解析审查结论
    auto-settings.ts  ~/.relay/auto.json
    prompts.ts    上岗说明 ONBOARD.md（手动 / 全自动两种口吻）
    journal.ts / lock.ts / session.ts / git.ts / status.ts / audit.ts / gate.ts …
  ops/          一个个动作（开始、上岗、交接、合回、退回、同步、收进、放弃、全自动）
    auto.ts       全自动流水线
  commands/     命令行
  server/       本机网页接口（只认 127.0.0.1 + 本端口；POST 必须 JSON；路径不许出项目）

```

## 全自动流水线（ops/auto.ts）

**下一步完全由交接记录推出来**（`decide()`），所以停下、崩掉、换进程之后都能接着跑：

| 情况 | 下一步 |
|---|---|
| 有别人的锁（桌面工人在岗等） | 停下，交给人 |
| 同步主线留下冲突，冲突标记还在 | 派人干活（上岗说明里写着先解决冲突） |
| 有没交接的改动 | 交接 |
| 还没有有改动的交接 | 第 1 轮干活 |
| 最近一次有改动的交接还没被审过 | 审查 |
| 审查通过 | 合回 |
| 审查要改、轮数没用完 | 下一轮干活（审查意见写进上岗说明） |
| 审查要改、轮数用完 | 停下，交给人 |

- **干活**：按团队顺序派主力；没做出改动（出错、没登录、额度用完）就记一次空交接让它下岗、换下一位。编程工具走 `harness.invoke(readOnly=false)`，接口模型走内置小代理。
- **交接**：复用手动模式的 `handoff()`；工人没写 NOTE.md 时，用它最后一句话当自述。
- **审查**：把「任务 + 全部改动（相对正式文件夹）+ 检查结果 + 上一轮意见」写进 `.relay/review-request.md`；编程工具只读模式读这个文件，接口模型直接收全文。审查员优先挑和干活的人不同的；都不行才自查。结论解析不了就换下一位审查员。检查没过、改到保护文件时，「通过」会被改成「要改」。
- **合回**：复用 `merge()`；正式文件夹后来有了冲突的新提交时，先 `syncMain()` 再派人解决冲突（最多两次）。
- **状态**：`~/.relay/projects/<项目键>/auto.json`（给网页看的进度，含每一步的日志路径和工具进程号）；日志在 `auto-logs/<运行编号>/`。叫停：同进程直接停；别的进程通过 `auto.stop` 标记文件通知。开始前把上次残留、还活着的工具进程结束掉。
- **新事件**：`review`（结论、问题、审的检查点、第几轮）、`auto`（开始 / 结束）；`run` 多了 `auto`、`round`。

## 工具调用参数（harness.ts）

| 工具 | 安全档干活 | 只读（审查 / 讨论） | 输出 |
|---|---|---|---|
| Claude Code | `-p --permission-mode acceptEdits --settings {"sandbox":{"enabled":true,"autoAllowBashIfSandboxed":true}}`，提示词走标准输入 | `-p --tools Read,Grep,Glob` | `stream-json`，最后一条 `result` |
| Codex | `exec -s workspace-write -C <副本> --json -o <文件> -` | `exec -s read-only --ephemeral …` | JSONL 事件；最后一句在 `-o` 文件里 |
| Cursor Agent | `-p --trust --force --sandbox enabled --workspace <副本> <提示词>` | `-p --mode ask …` | `stream-json`；取最后一条 assistant（`result` 会把所有话拼在一起） |
| ZCode | `zcode.cjs -p <提示词> --cwd <副本> --mode edit` | `--mode plan` | 文本 |
| Antigravity | 只有完全放开：`--dangerously-skip-permissions --sandbox` | `--mode plan` | `stream-json` |

完全放开档：Claude `--dangerously-skip-permissions`、Codex `--dangerously-bypass-approvals-and-sandbox`、Cursor `--sandbox disabled`、ZCode `--mode yolo`。

加一个新工具：在 `HARNESSES` 里写 `locate / login / model / invoke`，输出格式不认识就用 `lines`（按行记日志、最后一段当回答），再在 `test/auto-unit.test.ts` 里加参数断言。

## 实测记录（2026-09-23，这台 Mac）

- Claude Code 2.1.263（经 api.deepseek.com，deepseek-flash）：安全档改文件 + 沙箱里跑命令，通过。
- Codex 0.155.0（ChatGPT 登录，gpt-6-astra）：`workspace-write` 改文件 + 跑命令，通过；只读审查，通过。
- Cursor Agent 2026.09.x（Grok 4.6 High Fast）：`--force --sandbox enabled` 改文件 + 跑命令，通过；`--mode ask --model cursor-grok-4.6-high-fast` 只读问答，通过（`--model grok-4.6` 不认）。
- Antigravity 1.2.x：已登录；`accept-edits` 模式遇到要确认的命令会整段停下，所以只在完全放开档派它干活。
- 端到端：`relay auto` 用 Claude Code 干活、Codex 审查，一个小改动 1 分 49 秒完成并合回。
- Grok CLI 没登录（用户在 Cursor 里用 Grok）；ZCode 命令行按官方参数接入，没实测。

## 测试

`npm test` = 编译 + `node --test dist/test/*.test.js`。

- `unit.test.ts` / `auto-unit.test.ts`：纯函数（上岗说明、审查解析、工具参数、输出解析、设置校验、团队排序、JSONC、密钥来源……）。
- `flow.test.ts` / `process.test.ts`：手动模式全流程、锁、Ctrl-C、冲突、退回、收进。
- `auto.test.ts`：假的 claude / codex 程序（参数、输出格式和真的一样）跑全自动的各种情况，外加假的 OpenAI 接口跑内置小代理。
- `server.test.ts`：起真的 `relay ui`，走网页接口的全自动和安全检查。

测试环境变量：`RELAY_HOME`（数据目录）、`RELAY_LOGIN_PATH=off`（只用给定的 PATH、不读登录 shell）、`RELAY_SCAN_APPS=off`（不去「应用程序」里找）、`RELAY_AUTODETECT=off`（接力台启动时不自动识别）、`RELAY_TERMINAL=off`、`RELAY_CLIPBOARD=off`。
